# Лицензия 1С в Docker: интерактивное получение через VNC (license-gui)

Конфигуратору (движок `gitsync` с configurator-бэкендом, Designer-операции)
нужна лицензия 1С — это требование платформы. `tool1cd`-движок работает
без лицензии. Программная лицензия получается **один раз** через VNC-сессию
и сохраняется в volume — все последующие запуски контейнера её подхватывают.

Подход позаимствован из образа `client` проекта kafka-tools: Xvfb (виртуальный
дисплей) + openbox (менеджер окон) + x11vnc (доступ к дисплею по VNC).

## Предусловия

| Что | Проверка |
|---|---|
| Клиент платформы в образе | `vendor/platform/client_8_3_27_*.deb64.zip` был на момент `docker compose build converter` (см. [vendor/README.md](../vendor/README.md)) |
| Учётная запись releases.1c.ru (ИТС) с правом на лицензию | — |
| VNC-клиент на хосте | TightVNC Viewer / TigerVNC / RealVNC Viewer — любой |

Проверить, что клиент в образе:

```powershell
docker compose run --rm --entrypoint bash converter -c "ls /opt/1cv8/current/1cv8*"
# должно быть: 1cv8 (врапер) и 1cv8.real (бинарник)
```

## Запуск сессии

```powershell
docker compose run --rm -p 127.0.0.1:15900:5900 converter license-gui
```

Разбор команды:

| Часть | Значение |
|---|---|
| `-p 127.0.0.1:15900:5900` | порт VNC контейнера 5900 публикуется на хосте как **15900**, только на loopback (из сети не видно). Если 5900 на хосте свободен — можно `-p 127.0.0.1:5900:5900` и подключаться к 5900 |
| `--rm` | контейнер удалится после остановки — лицензия НЕ потеряется: она в volume `v8home` и/или `./licenses` (bind-mount) |
| `license-gui` | скрипт в образе: поднимает Xvfb :99 → openbox → x11vnc (порт 5900, без пароля) → запускает Конфигуратор на пустой временной ИБ |

После старта скрипт печатает в консоль:

```
==============================================================
  VNC:      vnc://127.0.0.1:5900  (без пароля)
  В 1С:     Получить программную лицензию (releases.1c.ru)
  Лицензия: /root/.1cv8 (volume v8home, переживает --rm)
  Стоп:     Ctrl+C
==============================================================
```

## Получение лицензии (в VNC-окне)

1. Подключись VNC-клиентом к `127.0.0.1:15900` (без пароля).
2. В окне 1С откроется Конфигуратор (пустая ИБ). При старте платформа сама
   показывает диалог о ненайденной лицензии — в нём сразу есть кнопка
   **«Получить программную лицензию»**. Если диалог закрылся: меню
   **Справка → Программная лицензия → Получить лицензию**.
3. Варианты получения:
   - **Через Интернет** — логин/пароль от releases.1c.ru (ИТС-учётка);
   - **По файлу запроса** — если политика безопасности требует оффлайн-цепочки.
4. Дождись сообщения об успешной активации (лицензия привязывается к
   аппаратному идентификатору контейнера, включая MAC — см. ниже).
5. Проверка (в другом терминале):

   ```powershell
   docker exec <имя_контейнера> bash -c "find /root/.1cv8 /var/1C/licenses -iname '*.lic'"
   # или на хосте: файл появится и в ./licenses (bind-mount в /var/1C/licenses)
   ```

6. Останов сессии: `Ctrl+C` в консоли с license-gui (или `docker stop`).

## MAC-адрес — важно

Программная лицензия привязывается к MAC-адресу. В `compose.yaml` MAC
зафиксирован (`V8_MAC_ADDRESS`, по умолчанию `02:42:AC:11:00:99`) и
применяется к ЛЮБОМУ запуску через compose (`run`/`up`). Правила:

- **не меняй** `V8_MAC_ADDRESS` после активации — лицензия станет невалидной;
- один набор «volume v8home + MAC» = одна активация; вторая машина/стенд —
  свой `.env` со своим MAC (и своя лицензия);
- если запустить контейнер мимо compose (`docker run` без `--mac-address`)
  и активировать лицензию там — на зафиксированном MAC она работать не будет.

## Что где хранится

| Путь | Что | Переживает `--rm`? |
|---|---|---|
| volume `convert2edt_v8home` → `/root/.1cv8` | хранилище программных лицензий платформы | да (named volume) |
| `./licenses` → `/var/1C/licenses` | файловые `*.lic` (можно просто положить сюда вручную — VNC не нужен) | да (bind-mount) |

## Типовые проблемы

| Симптом | Причина / решение |
|---|---|
| `ports are not available ... 5900` | на хосте 5900 занят (часто локальный VNC-сервер, напр. tvnserver) → используй другой порт: `-p 127.0.0.1:15900:5900` |
| окно 1С есть, но «Не найдена лицензия» после активации | запущено с другим MAC (мимо compose) или изменён `V8_MAC_ADDRESS` → вернуть MAC, при котором активировали |
| `1cv8: error while loading shared libraries` | старый образ без GUI-зависимостей → пересобрать `docker compose build converter` |
| нет кнопки «Получить лицензию» | нет клиента платформы в образе (см. предусловия) |
| VNC подключается, но чёрный экран без окна 1С | старая версия скрипта запускала врапер (xvfb-run создавал второй дисплей) → пересобрать образ: `1cv8.real` запускается на :99 напрямую |
